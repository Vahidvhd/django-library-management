About:

This project is a web-based library management system developed with Django. It provides a structured way to manage books and authors through a simple administrative interface. Users can browse the book catalog, view detailed information about each book, track availability status, and maintain author records. The project demonstrates the implementation of database relationships, CRUD operations, and server-side rendering using the Django framework.
